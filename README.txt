RationSetu - Clean Regenerated Version
======================================

1. Open a terminal in this folder.
2. (Optional) Create a virtual environment:
   python -m venv venv
   venv\Scripts\activate
3. Install dependencies:
   pip install -r requirements.txt
4. Start:
   python app.py
5. Open:
   http://127.0.0.1:5000

ESP32:
- The application works in DEMO MODE if the ESP32 serial port is unavailable.
- To use hardware, set ESP32_PORT before starting, e.g.:
  set ESP32_PORT=COM3
